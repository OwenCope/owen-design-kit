# Instructions for any coding agent

This project follows the apple-craft skills. Before doing any work:

1. Read `~/Developer/owen-design-kit/plugins/apple-craft/skills/apple-design/SKILL.md`.
2. Reuse `design-patterns/SKILL.md` (same folder) for any component; run `design-review/SKILL.md` before showing work.
3. For a Mac or iOS app, read `macos-app-design/SKILL.md`. For a website, read `web-design/SKILL.md`. For glass, read `liquid-glass/SKILL.md`.
4. Before writing any text, read `product-writing/SKILL.md`. Before any release, read `release-notes/SKILL.md` and `ship-and-verify/SKILL.md`.
5. In Owen's projects, also read `~/Developer/owen-design-kit/plugins/owen-design/skills/working-with-owen/SKILL.md` and the matching `project-<name>/SKILL.md` there. Owen's picks override the defaults.

Follow these over your own defaults. The standard: it should look and read like Apple made it.
