# Instructions for any coding agent

This project follows Owen's design kit. Before doing any work:

1. Read `~/Developer/owen-design-kit/plugins/owen-design/skills/working-with-owen/SKILL.md`.
2. Read `apple-design/SKILL.md` in the same folder.
3. For a Mac/iOS app, read `macos-app-design/SKILL.md`. For a website, read `web-design/SKILL.md`.
4. Read the `project-<name>/SKILL.md` for this project, if one exists. If not, follow `new-project-setup/SKILL.md`.
5. Before writing any text, read `product-writing/SKILL.md`. Before any release, read `release-notes/SKILL.md` and `ship-and-verify/SKILL.md`.

Follow them over your own defaults. The standard is: it should look and read like Apple made it.
