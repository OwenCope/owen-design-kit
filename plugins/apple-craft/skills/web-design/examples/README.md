# product-page.html — reference product page

Shows a full page for Harbor (menu-bar app): nav, hero, Mac scene,
features, FAQ, closing, footer — with light/dark themes and motion.
Structure and Mac parts come from `mac-props`; MorphLabel button,
FAQ disclosure and tokens from `design-patterns`; page rules from
`web-design`. It has no signature moment on purpose: design one per
product with `signature-moments`, never copy this page's look as one.

## Copy the craft, not the page

Copy how the parts are built: the button, the FAQ, the real-size Mac screen, the spacing, the motion. Never copy the page itself. A page that comes out as Harbor with new words fails review. Before showing, name what your page does differently from this one (layout order, hero picture, colours, feature visuals, signature moment); if you can't, it fails review.
